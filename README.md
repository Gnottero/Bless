# Bless

Redesign del sito ufficiale di [Bless](https://blesscardgame.com), il gioco di
carte per due giocatori di Luminous Vine Studio.

Dentro ci sono la home, il database delle 62 carte con ricerca e filtri, una
pagina per ogni carta con la carta in 3D e il regolamento completo con il
glossario.

Fatto con Next.js 15, TypeScript e CSS Modules.

## Avvio

```bash
npm install
npm run dev
```

Per la build di produzione: `npm run build` e poi `npm start`.

# Bless

Redesign del sito ufficiale di [Bless](https://blesscardgame.com), il gioco di
carte strategico per due giocatori di Luminous Vine Studio.

![Home](docs/screenshots/home.webp)

Il sito riprende lo stile delle carte: fondo di pergamena, tratti a inchiostro
e i colori delle cornici. Si può consultare il database completo delle 62
carte, leggere il regolamento con il suo glossario e avviare una partita
online contro il Bot o contro un amico, direttamente dal browser.

Realizzato con Next.js e TypeScript.

## Avvio in locale

```bash
npm install
npm run dev
```

Il sito è disponibile su http://localhost:3000.
